# Sanity check — September 2026

A pack-wide review against current ComfyUI (master) and ComfyUI_frontend
**1.55.13**, run in both renderers: **Nodes 1.0** (LiteGraph canvas) and
**Nodes 2.0** (Vue nodes, `Comfy.VueNodes.Enabled`). Every claim below was
checked against the ComfyUI or frontend source, and the numeric ones were
measured. The fixes are the commits on this branch after `c9385b7`. Each
commit message says what broke and how it was verified. All 22 test scripts
pass. The two that need a running server skip, and `verify_profiler.py` needs
`--cpu` on a machine without a GPU.

This file keeps what is **still open**, the **behaviour changes** the fixes
introduce, and what was **checked and found fine** under Nodes 2.0. Delete it
once it's been triaged.

---

## Behaviour changes introduced by the fixes

These fix bugs, but a re-queued old workflow can produce different output:

| Node | Change |
| --- | --- |
| Exposure Merge | Brackets with no 0 EV stop (symmetric 2 or 4, custom stops, `reference=first`) now land at plate exposure. They were up to −0.75 EV dark. |
| Crop / Uncrop / Animated Crop | No [0,1] clamp on image data, so HDR survives. Rotated crops are ~0.5 px different (now exact). Animated Crop no longer resamples a constant rect. Uncrop no longer feathers edges on the frame border. |
| Grade / Animated Grade | With `clamp_black` off, negatives now survive the gamma; before, the toggle did nothing. |
| Roto | Masks are antialiased and no longer biased up-left by vertex truncation. |
| Advanced Blend | Radii ≤ 0.5 now blur (one tap). They were a no-op. |
| Batch Format / WAN Batch Format | With `round_up` off, the length never lands below the input. A clip that fits one WAN window snaps to 4k+1 instead of padding to a full window. |
| WAN Batch Format | `debug_window_viz` is rendered at a 128 px long edge (it is flat colour). |
| VACE Batch Tool | A multi-frame keyframe input fills every frame from its index, not just the first. |
| Video Loader | 10-bit/alpha clips with a 90°/270° display matrix decode at the displayed size. |
| Filename Prefix | `..` path levels and illegal separator characters are rejected. |
| Fullscreen editors | While maximised, core shortcuts (Ctrl+Enter, Ctrl+S) are inactive, as they are under any core dialog. |

## Still open — worth doing

1. **Preview payloads accumulate in server history.**
   - Roto, Animated Crop/Grade, Grade, Advanced Blend, Layered Images, HDR Tonal Composite and SeC return MBs of base64 JPEG in `ui`. Measured: 7–21 MB for 120 frames, ~15–20 MB per SeC run.
   - ComfyUI keeps that in prompt history (up to 10 000 entries, `execution.py`) and re-sends it on fully cached runs.
   - Fix: write previews to `folder_paths.get_temp_directory()` and return `{filename, subfolder, type: "temp"}` refs, as `PreviewImage` does.
2. **SeC is invisible to ComfyUI's model management.**
   - The ~7.35 GB model lives in a private cache moved with `.to()`. It isn't evicted when other models need VRAM and isn't released by "Unload models".
   - Loading it OOMs if Flux/SDXL is still resident.
   - Fix: wrap it in `comfy.model_patcher.CoreModelPatcher` (see `comfy_extras/nodes_frame_interpolation.py`) and call `load_models_gpu` before segmenting.
3. **Editor metadata in the serialised `state` string forces re-execution.**
   - Roto, Animated Crop and Animated Grade write `imgW`/`imgH`/`frameCount` into `state` after the first run and on any clip change. `state` is part of the cache key, so the next queue re-runs the node and everything downstream with no user edit.
   - Fix: move them to `node.properties`.
   - Related: Animated Crop's Python fallback rect (512² at the origin) doesn't match the editor's centred seed, so the very first run differs from what the editor then shows.
4. **Roto Ctrl+Z runs two undos.**
   - ComfyUI's ChangeTracker listens on `window` in the capture phase, so the editor can't stop it. Roto's local undo and a full graph reload both happen.
   - The reload wipes Roto's history, closes fullscreen, and can undo an unrelated change.
   - Pick one: drop the local undo on the node, since the state is in the widget and core undo covers it. Fullscreen is already modal and is fine.
5. **Compute runs on the input device (usually CPU).**
   - Advanced Blend and Layered Images do all their blurs on CPU. A 300-frame 4K clip at split 32 is ~20 min.
   - Moving each chunk to `comfy.model_management.get_torch_device()` is a large win.
6. **Animated Crop is ~25× slower than Crop for the same rect.**
   - It allocates full-canvas masks and resizes one frame at a time.
   - Fix: group frames with identical rects, preallocate, and make one batched `grid_sample` for rotated runs.
7. **Grow / Erode with large radii takes minutes.**
   - The elliptical cv2 kernel costs O(r²): 1.7–3.2 s per 1080p frame at r=128, 9.7 s at r=256.
   - Fix: `cv2.distanceTransform` for near-binary masks (radius-independent), or an iterated small disc.
8. **BAT DOM widgets serialise a trailing `""` into `widgets_values`.**
   - `addBatDOMWidget` sets `options.serialize: false` but not `widget.serialize = false`. The workflow serialiser only checks the latter.
   - Video Combine now tolerates it. Changing the helper would shift positional values on any node whose DOM widget precedes a serialised widget, so audit node by node first.

## Still open — Nodes 2.0 gaps

- **Middle-drag inside Crop / Animated Crop / Roto** pans the graph. The Vue TransformPane forwards every middle-button event. Wheel zoom now works after one click in Roto and Animated Crop. Everything works in fullscreen.
- **Crop, Advanced Blend and Layered Images never take focus,** so the wheel over them always zooms the graph. Taking focus would also mean stopping their keys, as Roto now does.
- **Video Loader trim hover.** The hairline and the `I`/`O` "set to hovered frame" keys don't work. WidgetLegacy never forwards hover moves to `widget.mouse`. Clicks, drags, buttons and arrows do work.
- **`GROW_FACTOR` is Nodes-1.0 only.** The Vue grid gives DOM widgets `auto` rows, so editors can grow without a ceiling. This is documented in `bat_node_layout.js`.
- **Vue nodes have no LOD/culling.** At the 5% canvas zoom that `bat_canvas_zoom.js` allows, every node's DOM is still painted.
- **Layered Images reload is not verified.** The dynamic inputs weren't checked for surviving save/reload in 1.55: core reorders inputs by definition order on configure. Test manually with 3+ layers wired.
- **HDR Tonal Composite view state.** The saved view mode, exposure and display transform are read before the node id is final on load, so they likely never restore on reopen.

## Still open — decisions for you

- **Grade vs Nuke.** Grade's formula scales `lift` by `multiply`, so it differs from Nuke's Grade when lift ≠ 0 and multiply ≠ 1. Example: lift 0.1 and multiply 2 map (0, 0.5, 1) to (0.2, 1.1, 2.0); Nuke gives (0.1, 1.0, 1.9). The docstring claims Nuke parity. Fixing it changes existing looks.
- **H.265 is all-intra.** x265 then signals the RExt profile and files are ~6× larger. Many hardware/OS decoders only take Main/Main10. The player always transcodes h265 anyway.
- **VACE `plate_image` without `plate_mask`.** It keeps an all-ones mask, and the default premultiply then replaces the whole plate with fill grey.
- **Blend divide mode** returns `cb/1e-6` where the source is black: a 5e5 firefly per black pixel with `clamp_output` off.
- **Uncrop's `lanczos`** goes through `comfy.utils.common_upscale` (8-bit PIL), so that one filter still clips HDR.
- **Rescale** has no way to clamp only negative ringing (lanczos undershoots to −5 on a 0→50 edge) and no MASK input/output.
- **Profiler config** (`sync_cuda`, `reset_peak`, sample rate) is process-global across armed clients.

## Missing features that would earn their keep

- **Registry metadata.** A `pyproject.toml` (`[project]` plus `[tool.comfy]`) so the pack can be published to the Comfy Registry and shows properly in ComfyUI-Manager.
- **Grid Merge** for Video Grid Split. It currently has no way back from overlapping tiles.
- **List-aware variants** of List Length / Index / Batch (`INPUT_IS_LIST`). Today they see a ComfyUI list one item at a time.
- **Keyframe easing** in Animated Crop / Animated Grade / Roto. Interpolation is linear only.
- **CI.** Every test here runs on CPU in a few minutes: quickjs for the JS, and ComfyUI on `PYTHONPATH` for the backend ones. `verify_profiler.py` needs `comfy.options.enable_args_parsing()` with `--cpu` on a GPU-less runner.
- **Example workflow.** `BAT_NodePack_All_Nodes.json` is missing the 13 nodes added since it was made: Loader, EXR Layer, Cryptomatte Matte and the ten utility nodes.

## Checked under Nodes 2.0 and fine

- **Hidden state widgets.** `type = "hidden"` plus `hidden = true` suppresses the row in the Vue renderer and the parameters panel, and the widget still serialises.
- **Widget callbacks and programmatic `widget.value` writes** flow through the widget value store. Format switching, derived pix_fmt, button relabels and preview-frame stepping all update in Vue.
- **Pointer maths in every editor.** The `clientWidth / rect.width` ratio cancels both LiteGraph's DOM-widget transform and the Vue TransformPane scale.
- **`getExtraMenuOptions`** is called by the Vue "More options" menu, so the Bypass Switch menu entries appear there.
- **Bypass Switch** toggles are core `toggle`/`combo`/`button` widgets rendered natively (not WidgetLegacy), and its mode changes are store-tracked.
- **`onExecuted`, `onResize`, `onRemoved`** fire in both renderers. Lifecycle teardown runs on delete, clear, workflow switch and convert-to-subgraph.
- **Alt+Enter** only binds core's existing `Comfy.QueueSelectedOutputNodes`, which ships unbound; it doesn't duplicate anything.
- **Canvas zoom floor.** The Vue TransformPane mirrors `ds.scale` with no clamp of its own, so the lowered floor works in both renderers.
- **The `*` wildcard type** validates in both directions on current master.
