# Sanity check — September 2026

A pack-wide review against current ComfyUI (master) and ComfyUI_frontend
**1.55.13**, run in both renderers: **Nodes 1.0** (LiteGraph canvas) and
**Nodes 2.0** (Vue nodes, `Comfy.VueNodes.Enabled`). Every claim was checked
against the ComfyUI or frontend source, and the numeric ones were measured. The
fixes are the commits on this branch after `c9385b7`; each commit message says
what broke and how it was verified.

A first round fixed the bugs the review found. A second round worked through
every item the review had left open. Both are summarised below, together with
the output changes a re-queued old workflow can see, and what is still open.

Every test script passes. The two that need a running server skip themselves.
`.github/workflows/tests.yml` runs them all against ComfyUI master on CPU for
every push.

## Behaviour changes

These fix bugs, but a re-queued old workflow can produce different output.
Where the change would alter a deliberate look, old workflows keep the old
behaviour and only new nodes get the new one. That case is marked **(legacy
kept)**.

| Node | Change |
| --- | --- |
| Exposure Merge | Brackets with no 0 EV stop now land at plate exposure. They were up to −0.75 EV dark. |
| Crop / Uncrop / Animated Crop | No [0,1] clamp on image data, so HDR survives. Rotated crops are ~0.5 px different (now exact). Animated Crop no longer resamples a constant rect. Uncrop doesn't feather edges on the frame border, and its lanczos uses a float resampler (SDR moves by ≤ ~2/255). |
| Grade / Animated Grade | `lift_mode` "nuke" follows Nuke's Grade: multiply no longer scales lift. **(legacy kept)** An API-format prompt from an old script has no `lift_mode` and gets "nuke". With `clamp_black` off, negatives now survive the gamma. |
| Roto | Masks are antialiased and no longer biased up-left. Ctrl+Z on the node is one core undo step. |
| Animated Crop | A new node's first run renders the editor's centred seed rect. **(legacy kept)** Saved empty states keep the 512² origin rect. |
| Advanced Blend / Layered Images | Radii ≤ 0.5 now blur (one tap). Divide over a black source gives 1 (or 0), not 1e5 fireflies. Both compute on the GPU when ComfyUI has one. |
| Rescale | New `ringing` option (off by default) and a MASK input/output (appended last). |
| Batch Format / WAN Batch Format | With `round_up` off, the length never lands below the input. A clip that fits one WAN window snaps to 4k+1. `debug_window_viz` is 128 px. |
| VACE Batch Tool | Multi-frame keyframes fill every frame from their index. A plate without a mask is kept instead of greyed. |
| Grow / Erode | Bit-exact, and much faster at large radii. Near-binary masks come out as exact 0/1 (≤1e-3 change). |
| Video Loader | 10-bit/alpha clips with a 90°/270° display matrix decode at the displayed size. |
| Video Combine | H.265 uses a normal GOP: Main/Main10 instead of all-intra RExt, about 6× smaller. |
| Filename Prefix | `..` path levels and illegal separator characters are rejected. |
| Canvas zoom | Under Nodes 2.0 the untouched floor stays at the stock 10%. An explicit setting is honoured. |
| Profiler | Settings are per browser; `/state` returns only the caller's runs. |
| Fullscreen editors | While maximised, core shortcuts are inactive, as under any core dialog. |
| Crop / Advanced Blend / Layered Images | Clicking into the editor focuses it, so wheel zoom works under Nodes 2.0. Under Nodes 1.0 that also selects the node. |

## Resolved in the second round

- **Preview payloads no longer live in the prompt history.** `bat_ui_ref.py` / `web/bat_ui_ref.js` store each editor's `ui` in a size-capped temp sidecar and send a token; every heavy node uses it.
- **SeC is under ComfyUI's model management** (`CoreModelPatcher` + `load_models_gpu`), so it can be evicted, unloaded and reloaded like core models.
- **No spurious re-runs.** Roto, Animated Crop and Animated Grade keep the plate size in `node.properties`, not in the serialised state.
- **Roto has a single undo.**
- **GPU compute** for Advanced Blend and Layered Images.
- **Animated Crop is batched,** with bit-exact output.
- **Grow / Erode** is exact and radius-independent.
- **Nodes 2.0 gaps closed:**
  - middle-drag pans the editor, not the graph;
  - wheel zoom works in every editor after one click;
  - Video Loader trim hover works (and now in Nodes 1.0 too);
  - the canvas-zoom floor stays at the stock 10%;
  - Layered Images' save/reload was traced and needs no change;
  - the HDR editors restore their views.
- **Decisions, as proposed above:** Grade Nuke parity (legacy kept); H.265 GOP; VACE plate; divide mode; float Uncrop lanczos; Rescale ringing and mask; per-client profiler settings.
- **Features:**
  - 🦇 Video Grid Merge;
  - 🦇 List Length (list), with core's Get Item From List / Create List covering the rest;
  - keyframe easing in all three animated editors;
  - `pyproject.toml`;
  - CI;
  - an example workflow with all 45 nodes.
- **DOM widgets no longer write a stray value into `widgets_values`.** Every editor's DOM widget was audited as the last widget on its node, so old saves load unchanged.
- **Found on the way:** Advanced Blend, Layered Images and the HDR editors built their localStorage keys before a loaded node's id was final, so every such node in a workflow shared one key. The full-resolution preview is now keyed per run. The editors' localStorage caches have a budget, because ComfyUI evicts its own unsaved drafts when the quota fills.

## Still open

- **Nothing has been clicked through in a browser.** All UI behaviour was checked against the frontend source and driven through the quickjs harnesses. A manual pass in both renderers is worth doing, especially:
  - the Roto and Animated Crop / Animated Grade ease pickers and undo;
  - middle-drag and wheel inside the editors under Nodes 2.0;
  - Video Loader trim hover;
  - reopening an old workflow that uses Grade, Rescale or Video Combine.
- **GPU paths were verified on CPU only:**
  - SeC's `load_models_gpu` round trip, and whether its 3 GiB working-memory estimate is enough;
  - Advanced Blend / Layered Images on CUDA (TF32 is held off around the blurs so parity holds).
- **Registry:** set `PublisherId` in `pyproject.toml` before `comfy node publish`.
- **Small performance leftovers in Animated Crop:** an animated zoom still resizes frame by frame, and an animated rotated rect builds a full-canvas mask per frame.
- **`GROW_FACTOR` is Nodes-1.0 only.** The Vue grid gives DOM widgets `auto` rows. This is documented in `bat_node_layout.js`.

## Checked under Nodes 2.0 and fine

- **Hidden state widgets.** `type = "hidden"` plus `hidden = true` suppresses the row in the Vue renderer and the parameters panel, and the widget still serialises.
- **Widget callbacks and programmatic `widget.value` writes** flow through the widget value store. Format switching, derived pix_fmt, button relabels and preview-frame stepping all update in Vue.
- **Pointer maths in every editor.** The `clientWidth / rect.width` ratio cancels both LiteGraph's DOM-widget transform and the Vue TransformPane scale.
- **`getExtraMenuOptions`** is called by the Vue "More options" menu, so the Bypass Switch menu entries appear there.
- **Bypass Switch** toggles are core `toggle`/`combo`/`button` widgets rendered natively (not WidgetLegacy), and its mode changes are store-tracked.
- **`onExecuted`, `onResize`, `onRemoved`** fire in both renderers. Lifecycle teardown runs on delete, clear, workflow switch and convert-to-subgraph.
- **Alt+Enter** only binds core's existing `Comfy.QueueSelectedOutputNodes`, which ships unbound; it doesn't duplicate anything.
- **Canvas zoom floor.** The Vue TransformPane mirrors `ds.scale` with no clamp of its own, so the lowered floor works in both renderers.
- **The `*` wildcard type** validates in both directions on current master.
